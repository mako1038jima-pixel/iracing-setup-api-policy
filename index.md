# Privacy Policy

This GPT Action connects to the iRacing setup consultation API.

The API may receive information that users provide during iRacing setup consultation, including:

- Driver alias
- Vehicle name
- Track name
- Setup notes
- Setup logs
- Telemetry summaries
- Tire data
- Lap times
- User-provided driving feedback

We do not intentionally collect passwords, API keys, payment information, email addresses, Discord IDs, or other sensitive personal information.

Authentication tokens are used only to verify access to the API. Access tokens are not shown to users and are not shared with third parties.

Data is used only to provide iRacing setup consultation, saved driver preferences, setup logs, telemetry findings, setup snapshots, and related analysis requested by the user.

Users may request deletion of saved setup logs, telemetry findings, setup snapshots, or driver preferences.
